# 🕸️ Job Market Web Scraper & Industry Analyzer

## 📌 Project Overview
This project is a practical, two-stage data science project designed to extract job postings from a live web page, structure the raw data, classify highly diverse job titles into clean industry groups, and generate a polished visual report. 

The project solves a common challenge in data collection: transforming messy, unstructured textual data scraped from the web into clean, actionable business insights. It consists of a dedicated Python web scraper and an analysis workflow built within a Jupyter Notebook.

---

## 📂 Repository Structure
* **`webscrapping.py`**: The initial Python script that requests the web page, parses the raw HTML, extracts data cleanly, and saves it.
* **`data_analysis.ipynb`**: The Jupyter Notebook that handles data loading, category keyword mapping, case-insensitive text classification, and data visualization.
* **`job_titles.csv`**: The structured data file generated by the scraper containing extracted records.
* **`scraped_market_data.png`**: The final high-resolution visual chart exported directly by the analysis script.

---

## 🚀 How It Works

### 1. Data Extraction (`webscrapping.py`)
The script sends a secure HTTP request to the target site (**Real Python's Fake Jobs board**). It leverages **BeautifulSoup** to break down the HTML layout:
* It isolates individual job components using the parent container class (`card-content`).
* It extracts three essential data fields: **Job Title**, **Company Name**, and **Location**.
* **Error Prevention:** Built-in conditional checks look for the existence of tags before fetching text, falling back to an `"N/A"` value if an item is missing, ensuring the scraper runs smoothly without crashing.
* Data is automatically compiled into a tabular structure and saved as `job_titles.csv`.

### 2. Industry Classification & Visualization (`data_analysis.ipynb`)
Because job titles on public boards are incredibly diverse and spread across multiple disciplines, the notebook implements a rule-based dictionary classification function:
* **The Mapping Strategy:** A custom dictionary categorizes jobs into 7 distinct industry domains (*Technology & IT, Healthcare & Clinical, Engineering & Hard Sciences, Media, Creative & Design, Finance, Legal & Business, Education & Public Service, and Management & Operations*).
* **Case Insensitivity:** The function forces both the titles and keywords to lowercase during scanning, ensuring accuracy regardless of varying typographical formats. Unmatched titles default gracefully to `'Other'`.
* **Premium Plotting:** The notebook builds a horizontal bar chart utilizing a cohesive `"mako"` gradient color scheme from **Seaborn**. 

---

## 📊 Visual Standards & Chart Aesthetics
To make the data immediately readable for presentations, several manual adjustments were coded into the chart:
* **Whole Numbers Only:** Uses `MaxNLocator` to force the horizontal count axis to display logic-based integers instead of confusing auto-calculated decimals.
* **Modern Border Design:** Removes the heavy top and right boundary lines (spines) and shifts the bottom/left lines to a soft gray (`#cccccc`) to create a clean, minimalist layout.
* **Direct Data Labeling:** Implements `plt.bar_label` to draw bold, precise totals right at the edge of each industry bar, removing any guessing work for the viewer.
* Saved at high definition (`dpi=300`) with tight bounding margins (`bbox_inches='tight'`) to prevent text cropping.
